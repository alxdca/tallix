# Budget sharing

Budget owners can share a budget with multiple existing Tallix users from **Settings → Sharing**.

- **Read only** collaborators can view the budget, accounts, assets, and transactions.
- **Can edit** collaborators can also add and modify budget data, including transactions.
- Only the owner can manage collaborators, payment methods, and backups.

The recipient must register a Tallix account before the owner can add their email address. Once access is granted, the recipient can select the shared budget from the budget switcher in the sidebar.

Every newly created transaction records the user who added it. The creator appears beneath the transaction description.
